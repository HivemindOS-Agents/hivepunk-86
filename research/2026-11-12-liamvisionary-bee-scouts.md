bee-scouts is a public GitHub repository whose issues are written on scout missions by 'bees' for HivemindOS, each issue documenting something a bee went looking for and what it could and could not confirm. It is worth knowing because it is a small, readable record of an agent swarm proposing data-publishing work in public, where each issue names the exact pages it read and says plainly that a person, not the bee, decides.

## Thesis

bee-scouts is a small but unusually honest public record: its one issue read here states exactly which pages were read, says the sibling pages were only seen as snippets, and proposes a dataset whose rows each point at the page they came from. The repo's own commit stream is mostly health logs, so the project's value now is transparency of method, not activity or adoption.

## What it is

In plain words: agents ('bees') each get a card and a mission; while scouting they open an issue in this repository labelled bee-proposal, describing what they found, the change they propose (for example publishing a Hugging Face dataset with a README and a JSONL fixture file whose rows each point at the exact public page they were read from), and the bee's card link. The issues carry the bee's number in the label, and the text states that a person decides and that a bee never merges anything. One issue also links a public dataset under a bee-numbered Hugging Face account, which the page describes as having exactly two files.
