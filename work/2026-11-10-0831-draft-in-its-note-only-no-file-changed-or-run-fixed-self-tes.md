The fix: in the self-test's case 4, the fixture should include text *outside* the script tag inside `<noscript>` so the test matches the tool's behavior. But the tool is correct: a `<noscript>` with only a `<script>` child has no visible text, so it's correctly reporting `noscript missing`. The self-test expectation was wrong.
